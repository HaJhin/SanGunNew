# 산군 (SanGun)

3D와 2D 도트 그래픽이 결합된 **2.5D 벨트스크롤 액션 게임**
3D로 구성된 배경 위에서 2D 도트 캐릭터가 움직이며 전투를 벌이는 방식으로 제작.

## 팀원 및 역할

| 이름 | 역할 |
| --- | --- |
| 김민형 | Unity 개발 |
| 조다니엘 | 2D 도트 그래픽 |
| 김수진 (팀장) | 3D 모델링 |
| 김민재 | 3D 모델링 |
| 박우람 | 게임 레벨링 / 시나리오 |

## 프로젝트 소개

- **장르**: 2.5D 벨트스크롤 액션
- **특징**: 3D 배경과 2D 도트 캐릭터를 결합한 비주얼, 벨트스크롤 특유의 진행형 전투 구조

## 개발 환경

- Engine: Unity
- Language: C#
